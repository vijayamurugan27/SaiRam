✅ First line (very important)
factorial(0, 1).


This says:

👉 If the number is 0, the answer is 1.

So Prolog is told:

🧠
“Stop here. Don’t go further.”

This is the stop rule.

✅ Now the main rule
factorial(N, F) :-


This means:

👉 We want to find the factorial of N
👉 The answer will be in F

✅ Step 1
N > 0,


Means:

👉 Only work if N is bigger than 0.

✅ Step 2
N1 is N - 1,


Means:

👉 Make a smaller number.

Example:
If N = 5
then
N1 = 4

✅ Step 3 (THIS is the heart of the program)
factorial(N1, F1),


Means:

👉 First find the factorial of the smaller number.

So Prolog says:

🧠
“Before I calculate factorial of N,
let me calculate factorial of N-1.”

✅ Step 4
F is N * F1.


Means:

👉 Now multiply

F = N × (factorial of N-1)

🧠 Very small example

You ask:

?- factorial(3, F).


Prolog does this:

factorial(3, F)
 → factorial(2, F1)
     → factorial(1, F2)
         → factorial(0, 1)


Now it comes back:

factorial(1) = 1 × 1 = 1
factorial(2) = 2 × 1 = 2
factorial(3) = 3 × 2 = 6


So:

F = 6

🧒 In one simple sentence

This line:

factorial(N1, F1),


means

👉 “Go and find the factorial of the smaller number first.”

And this line:

F is N * F1.


means

👉 “Multiply my number with that result.”

🟢 Final simple meaning

Your whole program says:

👉 If number is 0 → answer is 1
👉 Otherwise

factorial(N) = N × factorial(N-1)
